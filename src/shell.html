开始使用 VIP Translate
  1. 填写 API 地址、密钥和模型，保存后测试连接。支持 OpenAI 兼容 Chat Completions 接口。
  2. 导入文件，选择 Sheet 和反馈列。可在“全部原始列”视图检查源数据。
  3. 展开术语管理，补充游戏名、活动名、host / 玩家姓名并保存。
  4. 开始翻译；默认每批 30 条、串行请求。暂停会等待当前批次结束；取消会中止当前请求，已完成结果保留。
  5. 点击中文单元格编辑。失败记录可单独重试；重新翻译需要明确确认，也可选择是否覆盖人工修改。
  6. 复制 TSV 或下载 Excel / 带 BOM 的 CSV。导出覆盖全部行，不受搜索与分页影响。

任务使用 IndexedDB 自动保存。刷新后可恢复；请使用同一浏览器、同一路径打开 HTML，移动文件、隐私模式或清理浏览器数据可能导致存储不可用。请及时导出备份。

Excel 导出会在原工作簿对象中追加列并保留其他 Sheet 和单元格数据、公式；复杂图表、宏、透视表及部分样式不保证完整保留。该工具不执行公式，复制到 Excel 的 TSV 使用带引号的字段保留换行和制表符。

Excel 解析库：SheetJS CE 0.20.3（Apache 2.0），已内嵌，无外部字体、脚本或埋点。
